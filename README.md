# Trốn Tìm Hóa Trang (HideAndSeek2D)

Game Prop Hunt 2D nhiều người chơi làm bằng Godot 4.7: người trốn hóa thành đồ vật trong nhà, người tìm phải tìm và hạ gục họ.

- `scenes/`, `scripts/`, `sounds/`: mã nguồn game (mở bằng Godot 4.7).
- `relay/`: máy chủ chuyển tiếp (Node.js, không cần thư viện) để chơi online và chơi trên web.
- `render.yaml`: cấu hình triển khai máy chủ chuyển tiếp lên Render.com (vùng Singapore, gói miễn phí).
